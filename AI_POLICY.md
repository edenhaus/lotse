# AI policy

AI-assisted development is welcome here, under two rules:

1. **A human owns every change.** The person who opens a pull request must
   be able to explain every line in it: what it does, why it is correct, and
   how the tests prove it. "The tool wrote it" is not an explanation, and a
   reviewer may ask for one at any time.
2. **No autonomous agent pull requests.** Agents may draft, refactor and
   test locally; a human reads, understands and submits. Pull requests
   opened by unattended agents are closed.

Agents working in this repository follow [AGENTS.md](AGENTS.md), which is
the same rule set humans follow. Nothing in this policy relaxes the
project's requirements on tests, documentation and design-first changes.
